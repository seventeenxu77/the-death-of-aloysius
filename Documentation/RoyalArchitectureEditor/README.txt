Royal Scene 本地三维建筑编辑器

日常编辑与交流
在画面中点击墙、门或建筑，拖动彩色坐标轴调整。W 移动、E 旋转、R 缩放、F 聚焦。
Shift 多选；选择层级树中的真实父组可一起移动它的子构件。Ctrl+Z 撤销、Ctrl+Y 重做、Ctrl+S 保存。
选择根节点或父组时，所属建筑统一显示青蓝色高亮，左上角显示区域名称；按 F 聚焦，Esc 取消选择。高亮遵循隐藏和剖切设置，只是查看提示，不改变建筑材质或方案。
查看室内时，勾选画面下方“自动隐藏近侧墙”：镜头与观察中心之间的竖直墙面及其饰条会临时隐藏，转动镜头自动更新，关闭后恢复。先选中房间或套院按 F 聚焦会更方便。地板、楼梯、家具保留；屋顶仍由“显示屋顶”单独控制。直接选中的墙保留显示以便编辑；自动隐藏不会写入方案，手动隐藏状态仍保留。
右侧可以输入精确位置/角度/缩放，并写下该对象的设计批注；变更页可以记录整份方案的说明。
顶部显示“已保存到本地项目”后，直接告诉助手“读取网页方案”，即可从 data/project.json 读取你的改动。
三侍卫房间有独立结构组；其他套院的部分房间在原Unity中仅是标记，相关墙/地板需要多选或选择上级结构组。
“文件”菜单可导出/导入方案 JSON，也可导出当前三维画面 PNG。旧剖面图册仍可以作为参考。
网页修改作用于独立方案，真实 Unity 场景没有自动回写；对象 ID 对应导出时的真实场景对象。

启动
双击“启动建筑编辑器.cmd”。服务在后台运行，浏览器打开 http://127.0.0.1:8731/ 。
再次双击会复用同一编辑器服务，不会重复启动。若端口由其他程序使用，启动器会停止并说明原因，不会关闭或替换该程序。
需要 Python 3.10 或更高版本；后端只使用 Python 标准库，无需 pip 安装。

独立方案
编辑墙、房间或楼层后，网页保存的是本目录 data/project.json。
这些修改不会自动写回 Unity 场景或 Assets。后续可由我们读取方案，再实施需要的 Unity 修改。
没有保存过方案时，读取返回空方案，不会提前创建 project.json。
每次成功保存会创建 data/history/ 内的版本档案，自动保留最近 50 份本服务生成的历史。
不要直接双击 index.html；必须通过本地网址打开，保存接口才可用。

多窗口保存
每次保存使用 baseRevision 检查是否仍基于最新方案；其他窗口已保存时返回冲突，不会静默覆盖。
遇到冲突请先保留当前修改内容，再重新载入最新方案进行调整。
方案备注与对象备注可以直接作为后续调整建筑的说明。

文件
model/scene.json、model/geometry.bin：从 Unity 导出的基础建筑，只读。
data/project.json：当前独立方案。
data/history/：最近保存的版本。
logs/server.log、logs/server-error.log：启动器创建的服务日志。
references/atlas/：保留的剖面图册、18 张图纸和完整 PDF；通过 /atlas/ 查看。

保存格式
schemaVersion: 1；sceneId 必须与基础模型一致。
overrides 使用模型节点 ID 作键，允许 position[3]、rotation[4]、scale[3]、name、hidden、note。
rotation 是 [x,y,z,w] 归一化四元数，长度误差不超过 0.001；不是欧拉角。
位置、旋转和缩放必须是有限数字，scale 每项必须大于零。
name 最长 200 字符，单对象 note 最长 4000 字符，方案 notes 最长 20000 字符。
全量保存 overrides：删除某个覆盖项即可恢复该节点基础状态。
revision 与 updatedAt 由服务端生成，客户端不能指定最终版本。
请求体上限 2 MB。未知字段、未知对象 ID、错误数据和跨站保存请求会被拒绝。

服务接口
健康接口：GET /api/health；读取方案：GET /api/project；保存方案：PUT /api/project。
正常启动器固定使用端口 8731。
